# Sharing and Discovery

**Related Requirements:** [Sharing Functionality](../Requirements/sharing-functionality.md), [Search Functionality](../Requirements/search-functionality.md)

## Use Cases

### UC-GU-012: Share Map State
- **As a** user
- **I want to** copy a share link that preserves map state and filters
- **So that** I can share specific views or collections with others

### UC-GU-013: Find Related Content
- **As a** user
- **I want to** find related photos by proximity and time period
- **So that** I can discover more historical content in areas of interest

## Acceptance Criteria
- Share links work across different browsers and devices
- Related content suggestions are relevant and contextual
- Map state is accurately preserved in shared links
