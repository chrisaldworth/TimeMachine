# Upload Operations

**Related Requirements:** [Admin Upload](../Requirements/admin-upload.md), [Content Curation](../Requirements/content-curation.md)

## Use Cases

### UC-AD-009: Direct Content Upload
- **As an** admin
- **I want to** upload content directly via the admin portal (single or batch), with full metadata controls
- **So that** I can add institutional or curated historical content

### UC-AD-010: Curate Featured Content
- **As an** admin
- **I want to** curate featured photos/collections for the public site
- **So that** I can highlight important historical content

## Acceptance Criteria
- Admin uploads bypass normal user restrictions
- Batch upload supports up to 500 photos at once
- Featured content is clearly marked on public site
- All admin uploads are logged with attribution
