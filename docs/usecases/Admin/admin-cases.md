🛡️ Admin Use Cases & Portal Scope

Version: 1.0 (draft)
Date: 19 September 2025
Prepared by: Chris Aldworth

⸻

1. Admin Portal Access
- As an admin, I can log into a dedicated admin portal area of the site.
- As an admin, I can manage access by assigning/removing admin roles to user accounts.

2. User Account Management
- View, search, and filter all user accounts.
- Edit user details, reset passwords (via email link), deactivate/reactivate accounts.
- View user activity (uploads, reports) with an audit trail.

3. Content Moderation and Management
- Review reported content in a triage queue with categories.
- Takedown or restore photos; edit metadata; soft-delete with retention.
- Bulk actions on selected photos (tag, reassign, publish/unpublish).

4. Upload Operations
- Upload content directly via the admin portal (single or batch), with full metadata controls.
- Curate featured photos/collections for the public site.

5. Security and Compliance Controls
- View moderation audit logs and export reports for compliance.
- Enforce content policies and user terms.

6. Constraints and Notes
- Admins have full control over all user accounts, uploads, and content.
- Licenses and offline support are out of scope initially; license policy TBD.
- Admin actions are logged for accountability.
